# Discord 환경 정책 JWT 관리 초안

`discord-policy-jwt.sql.draft`는 환경별 Discord 워크플로 정책을 운영자 JWT에 연결하기 위해 작성 중인 SQL이다. 이 파일은 마이그레이션이 아니며 적용하거나 운영에 사용해서는 안 된다. API 라우트, 권한 설정 도구, UI 및 통합 테스트는 아직 구현되지 않았다.

초안은 JWT 사용자별 조회·변경·감사 권한, 요청 ID 재사용, revision 충돌 감지 및 감사 기록을 구상한다. 현재 감사 조회는 JWT 권한만 확인하고 별도 DB 로그인 감사 권한은 확인하지 않으므로 권한 모델을 정리해야 한다. 제한된 DB 로그인과 JWT를 이용한 환경 격리, 권한 회수, 동시 변경, 요청 재시도 및 감사 실패 시 전체 롤백도 검증해야 한다. 구현을 완료하고 검토·테스트한 후에만 실제 API 마이그레이션으로 옮긴다.

현재 지원되는 환경 정책 관리는 워커 0207과 `delivery-reconcile` CLI이며 자세한 권한 및 운영 절차는 [워커 README](../../apps/worker/rust-queue/README.md)를 참고한다.
