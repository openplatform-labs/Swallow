# Resend 429 운영자 처리 설계 초안

이 디렉터리의 SQL은 진행 중인 설계 기록이며 실행 가능한 마이그레이션이 아니다. 자동 마이그레이션 경로 밖에 `.sql.txt`로 보관한다. 운영 데이터베이스에 적용하지 않는다.

워커 0167과 API 0093은 시도 UUID의 생성 및 조회만 구현한다. 이곳의 식별자 관련 파일은 이전 초안으로 남겨 둔 참고 자료이며 정식 마이그레이션이 아니다.

목표는 발송 시도 UUID를 확인한 뒤 권한이 있는 운영자가 즉시 재시도 또는 `Retry-After`에 따른 지연 재시도를 선택하고, 요청 중복 방지와 감사를 제공하는 것이다. 현재 SQL은 초안이며 순서·보안·동시성·기존 데이터 이관을 검토하지 않았다. 특히 기존 CLI와 구버전 워커는 제안된 시도 식별자 검사를 강제하지 않는다.

남은 작업: 수동 판정 SQL 마이그레이션 검토 및 구현, Rust 인증 API와 Angular UI 연결, 제한된 DB 역할을 이용한 권한·테넌트 분리·경합·롤백 통합 테스트, 실제 환경 및 원본 Novu와의 비교 검증. Resend 429나 HA 환경에서 검증했다는 뜻이 아니다. 완성 후에만 정식 마이그레이션으로 옮기고 실행 및 운영 절차를 문서화한다.
